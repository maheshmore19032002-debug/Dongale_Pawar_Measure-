# Dongale_Pawar_Measure
User-friendly GUI for analyzing memristor Pinched Hysteresis Loops (PHL), calculating performance metrics, and visualizing switching stability and reliability.
<br>
This project provides an interactive GUI for memristor I–V data analysis. It automates loop area calculations, symmetry assessment, variability analysis, and performance comparison across multiple memristor devices using numerical integration and Functional Data Analysis techniques.
